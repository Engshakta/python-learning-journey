# Enterprise Backend Engineering & Python Certification Journey

This repository documents my transition from a full-stack JavaScript engineer to a Python backend engineer through an intensive, structured capacity-building program.

## Objective

Achieve the following OpenEDG Python Institute certifications:

- **Phase 1:** PCEP – Certified Entry-Level Python Programmer
- **Phase 2:** PCAP – Certified Associate in Python Programming
- **Phase 3:** PCPP1 – Certified Professional Python Programmer Level 1
- **Phase 4 (Stretch Goal):** PCPP2 – Certified Professional Python Programmer Level 2

The long-term goal is to architect production-ready backend systems, develop robust APIs, and strengthen Linux-based enterprise infrastructure engineering skills.

---

## Learning Strategy

To ensure absolute resource efficiency and discipline, this roadmap is executed under a strict "Zero-Waste" risk control policy, gating every phase with rigorous mock-exam benchmarks. 

- Daily coding practice (14+ hours/day sprint capability)
- Weekly GitHub commits and transparent progress tracking
- Project-based learning (focusing on system automation and data handling)
- Strict Linux command-line development workflow
- Continuous debugging and problem-solving practice following PEP 8 standards
